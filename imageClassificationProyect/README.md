
ResNet 18 model for predicting tree species, with an API for live classification.
Dataset used: https://datasetninja.com/urban-street-tree-classification 

Files:
- newTrain.ipynb: code for the classifier.
- main.py: old version of the code without ResNet.
- app2.py: code for the API.
- class_names.json: names of the species classified.
- tree_classification_model.pth: trained model.
